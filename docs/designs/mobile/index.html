Design notes
Navigation
Bottom tab bar — 5 tabs: Home, Players, Teams, Games, More. The More sheet surfaces Seasons, Leaders, Compare, and Data Sources. Tab icons use the same geometric glyphs as the desktop nav.
Layout pattern
Single-column cards with 16px horizontal padding. Desktop's 3-column sidebar layouts collapse to stacked sections. Tables scroll horizontally within cards when content overflows.
Touch targets
44px minimum tap target height. Filter chips are 36px. Segmented controls are 40px. Tables use 40px row height. Bottom tab bar items are 64px with icon + label.
Form factor
390 × 844px viewport — iPhone 14 baseline. Dynamic Island / notch handled with 44px safe area at top. Home indicator safe area (34px) at bottom. Dark mode only.
