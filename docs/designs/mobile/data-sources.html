Data caveats
Federal League (1914–15) included in Lahman + partial Retrosheet. Flagged with league=FL filter.
Negro Leagues (1920–48) partial play-by-play via Retrosheet NLG files. Coverage <60% of games.
Statcast era (2015+) exit velocity, spin rate, and launch angle data only via MLB API. Not available pre-2015.
Salary data is Lahman-sourced (1985–2016 only). Incomplete for pre-1985 and post-2016 seasons.
